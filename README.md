<h1 align="center">PGPatcher - Mesh and Texture Patcher for Skyrim</h1>

A dynamic mesh and texture patcher for the Elder Scrolls V: Skyrim.

## Mirrors

* [Nexus Mods](https://www.nexusmods.com/skyrimspecialedition/mods/120946) - See this page for a better user-facing description of the project.

## Translations

PGPatcher has several non-English localizations supported by the community. English (`en.json`) is default - the badges below show how much of it each translation currently covers, and are updated automatically whenever the translation files change. Click a badge for the exact list of strings that language is missing. Contributions are very welcome; add or update a file in [PGPatcher/translations](https://github.com/hakasapl/PGPatcher/tree/main/PGPatcher/translations).
